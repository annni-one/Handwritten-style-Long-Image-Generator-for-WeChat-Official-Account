# 公众号手账长图 · 自动排版工具

输入 **一整篇纯文字** + **一张风格参考图**，自动生成手账风 900px 宽竖版长图，导出 PNG。全程本地运行，图片不上传云端。

## 启动

```powershell
npm run serve
# 打开浏览器访问 http://127.0.0.1:5399
```

## 使用流程（网站页面上的 5 步）

| 步骤 | 操作 | 说明 |
|---|---|---|
| 01 上传参考图片 | 点击/拖拽图片 | 决定背景色调 + 手账贴纸主体（自动抠图，保持原图样貌） |
| 02 粘贴整篇文案 | textarea 粘贴纯文字 | 点「智能分节」自动分段抽小标题；支持 `## 小标题` 手动标记 |
| 03 样式与封面 | 背景模式 / 标题 / 导出宽度 | 图片背景（模糊·提亮·渐变遮罩·颗粒）或纯渐变；900px / 1800px |
| 04 编辑分节 | 右侧分节卡片 | 标题、正文均可改，可增删节 —— **分节结果可编辑** |
| 05 生成结果 | 点「生成公众号长图」 | 预览 + 一键下载 PNG |

## 制作流程模板（代码管线）

```
图片 ──► ① analyze   提取主色调 / 点缀色 / 墨色
   │     ② cutout    ONNX 掩码 ∪ 泛洪剪影 → 补洞 → 裁残字 → 羽化 → 免抠贴纸（带柔和阴影）
文案 ──► ③ segment   自动分段 + 抽小标题（结果可在页面编辑）
   │     ④ layout    手账模板：章节头 01/02、便签文字框、装饰点缀（数量适中）
   │     ⑤ render    Playwright(Edge) 截图 → PNG（高 900×N 自适应）
```

- 核心理念：**AI 决策 + 代码确定性渲染**，不使用图像生成模型，主体绝不重绘。
- 抠图模型：`models/isnet-general-use.onnx`（rembg isnet，本地推理）。

## 提速机制（2026-02 更新）

| 场景 | 耗时 |
|---|---|
| 同一张图再次生成 | **~1.5–2 秒**（抠图结果按图片哈希落盘缓存） |
| 快速模式（不抠图） | **~1.5–2 秒**（相框卡+装饰替代免抠贴纸） |
| 全新图片 + 精细抠图 | ~5.5–7.7 秒（仅首次，之后同图秒回） |
| 1800px 高清导出 | 另 +5–6 秒（像素量是 900px 的 4 倍，建议日常用 900px） |

实现：① ONNX 模型进程内只加载一次 ② Edge 截图浏览器常驻复用 ③ 抠图磁盘缓存 `out/.cache/` ④ 服务启动即预热模型+浏览器 ⑤ 控制台输出每步耗时日志。

## 文件结构

```
src/
  server.mjs    本地服务（页面 + /api/segment + /api/generate）
  pipeline.mjs  5 步管线（CLI 与网页共用）
  analyze.mjs   调色板 / 点缀色
  cutout.mjs    抠图（ONNX + 泛洪 + 后处理）
  segment.mjs   文案分节
  layout.mjs    手账 HTML/CSS 模板
  render.mjs    Edge 无头截图
public/
  index.html    网页工具界面
models/         isnet-general-use.onnx
out/            生成的长图与中间产物
```

## CLI（命令行用法）

```powershell
node src/pipeline.mjs --img 参考图.png --text 文案.txt --title 标题 --out out/long.png
```
